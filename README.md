# E-commerce Sales Prediction using Machine Learning

## Project Overview
This project uses machine learning regression to predict e-commerce sales amounts based on dataset features. It demonstrates the basic workflow of building and evaluating a regression model using Python.

## Objective
To predict `total_amount` using the available e-commerce dataset features and evaluate the model's performance.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Google Colab
- Machine Learning (Regression)

## Dataset
The project uses an e-commerce dataset containing sales-related information. The target variable is `total_amount`.

## Model Training
The dataset features are used to train a regression model to predict the target variable, `total_amount`.

## Model Evaluation
The model achieved an R² score of approximately **0.763** in the earlier evaluation.

An R² score measures how well the model explains variation in the target values. Actual performance may differ depending on the train-test split and evaluation method.

## How to Run
1. Download or clone this repository.
2. Open the `.ipynb` notebook in Google Colab or Jupyter Notebook.
3. Upload the required dataset if it is not included.
4. Run the notebook cells in order.

## Learning Outcomes
- Loading and exploring a dataset using Pandas
- Selecting features and a target variable
- Training a regression model
- Evaluating model performance using R²
